# SEL 可读显示独立改进稿 — 2026-11-08

本目录仅包含离线实现、测试和整合预览；没有修改已发布 RC4，没有连接 BMC，也没有执行刷写。目标是让现有 P6 的 16 条 SEL 显示能说明事件含义，同时保持完整原始记录可核查。

## 实现边界

- 保持 `V_COUNT=41`、每项 `char[160]`、16 个 SEL 记录槽位；原生 IFR、字符串 ID、读取命令、配置写入代码均不变。
- 标准 `0x02` 记录显示记录 ID、时间、传感器类型和编号、ASSERT/DEASSERT、事件类型／偏移及已知事件含义。
- 已明确解释阈值事件、通用状态事件、标准电源事件、版本变更事件和 Watchdog2 事件。其他传感器专用事件显示类型／偏移；不猜测 OEM 内容。
- `0xC0–0xDF` 为有时间戳 OEM 记录，`0xE0–0xFF` 为无时间戳 OEM 记录。其余非 `0x02` 类型标为 UNKNOWN，修正原程序将所有非 `0x02` 都标作 OEM 的行为。
- 每条记录末尾保留全部 16 字节的 32 位十六进制字符串。未缩放 Event Data2/3，未推断实际 PSU1／PSU2 名称、FRU 或健康结论。仅凭 DEASSERT 不能断言故障恢复，例如 Presence 解除。
- 仅解释 EvM Revision `0x04` 的事件语义；其他版本保留版本号和完整原始数据。
- `<0x20000000` 的时间字段显示 `PRE+数值s`，表示编码处于未初始化时间范围，不推算日历，也不声称这是可靠的实际运行时长。`0xFFFFFFFF` 显示 `TIME?`。其余显示 `BMC@年-月-日 时:分:秒`，只转换 BMC 存储值，不声称 UTC、现场时区或经过历史时钟修正。
- 使用现有原生页面。133 字符的较长记录可能占多行，真实 BIOS 的换行、滚动及可读性仍需整合后验证。

## 验证结果

15 项测试全部通过，共 48,305 次带前后缓冲区哨兵检查的调用。覆盖全部输出容量 0–160、非法长度和空指针、事件方向、事件与传感器类型的交叉解释、OEM／保留类型、未初始化时间边界、2038 年边界、2000 年闰日及 2100 年非闰年、20,000 条确定性随机记录。

完整 16 字节原文均保留在容量 160 的有效记录输出中。当前覆盖矩阵的最长文本为 133 字符，包含末尾原始数据，留有 NUL 空间。格式化前后输入缓冲区不变。

整合预览对实际 P6 头文件执行了编译期检查，并将新 transport／decoder 与原 P6 其余对象链接成 EFI 驱动：41 项、160 字符、16 条记录 ABI 均通过；x64、EFI Boot Service Driver、PE 校验和和无导入检查通过。预览大小 383,488 字节，相比原 P6 373,248 字节增加 10,240 字节。这个预览不含 CAP 封装，未验证固件卷空间，也不是交付刷写包。

以下来自 `analysis/hero_ipmi_p5_field_20261104/transactions.json`，是 11 月 4 日采集数据的离线解码，不是本轮新采集或当前 29 条 SEL 的逐条验证。

```text
SYS #0001 PRE+315533864s PSU(08)#E3 ASSERT E=6F/0 Presence | 01000228AACE1220000408E36F00FFFF
SYS #0002 PRE+315533864s PSU(08)#E8 ASSERT E=6F/1 Failure | 02000228AACE1220000408E86F01FFFF
SYS #0003 PRE+315533864s Version(2B)#FB ASSERT E=6F/4 HW revision invalid/unsupported | 03000228AACE122000042BFB6F04FFFF
```

这些事件说明记录的标准语义；不根据历史事件宣称电源当前故障，也不能仅据第三条确认是哪个 BIOS／板卡版本不匹配。
