# W890 0603 页面代次与会话分离

此派生观察器修正了一个兼容问题：普通设备的 FORMS 更新不再使整个 BIOS 私有会话永久失效。安全身份代次 `epoch` 与页面目录代次 `catalog_generation` 分开；未经许可的 Setup 包变化、无效空 HII 通知和目录代次耗尽仍撤销身份。

每张 effect、manage、lease 票据在创建时记录目录代次。其他 HII 的页面变化会使旧票据验证失败，但不会提前清除其占用状态。只有原持有者退出后才能创建新票据，避免重入复用同一地址，让旧调用误以为取得了新证明。普通字符串通知不会改变 FORMS 代次。

`no_catalog_generation(uint64_t *out)` 是只读查询，仍要求真实私有 native visit。它不产生页面、回调或变量权限。页面识别组件须在导出 HII 和读取原生对象前后比较代次，发生变化即丢弃本次快照。历史分配仍按自己的分配寿命和 BIOS visit 跟踪，不能仅因目录变化就假定已经释放。

九个实际 PE 用例通过：三种 FORMS 通知、锁定 Ai Tweaker、不在私有会话内查询、票据失效与重入、字符串更新、原持有者退出后的新证明、异常 Setup 更新及空 HII 通知。通知函数是组件通过真实注册流程交出的地址。测试会进入实际编译的私有 Loop 包装器；原 BrowserLoop 中段、UEFI 服务、对象和调度仍为明确模型，不能称完整 BIOS 运行。

`test_consumer.c` 只属于这个测试 DLL；它的真实 CALL 窗口被测试安装记录绑定。它不访问私有状态、不提供 owner 布尔值，使用真实 scope API 和一个独立的模型变量。整合时仅采用 `visit/observer08.c` 中的生产修改及 `api.h`，不得带入两个 `og08_test_*` 入口或它们的调用窗口。

该组件尚未接入完整映像，旧 navigation05 的其他页面、SendForm 和非空刷新限制不由此 DLL 单独解决。后续需与 foreign_page08 和 navigation08 一起重新链接和验证。

开发中两个测试夹具错误已修正：最初选用的中断回程地址与旧 STOP 地址重合；NO_IDENTITY 的 fault 字段偏移应为 96。最终九个用例完整重跑通过；这些修正未改固件或模拟原生返回值。
