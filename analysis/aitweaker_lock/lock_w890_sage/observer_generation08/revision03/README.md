# 第三版：服务返回复核和票据所属栈帧

本版修正独审实际复现的两类问题，原第一、二版及失败证据均保留。

1. 固件服务可能在返回前触发已注册的通知。身份、管理票据及冷启动发布检查在服务后再次核对状态；不再返回“之前有效、现在已经过期”的结果。
2. 嵌套 native Loop 返回时，只退休属于该栈帧和深度的票据。外层持有的票据不会被内层清除：未更新时返回外层仍有效；目录更新后保持失效和占用，直到真正的原持有者退出。

九项原有实际 PE 回归全部通过。独立审查另执行七项反例与正例，包含原 `B8DC CALL` 进入真正私有嵌套 Loop 后的两种代次情况。测试没有直接写观察器私有状态，也没有通过 owner 布尔值赋予权限；服务、页面和调度时序仍是明确夹具，未证明完整 GUI。

生产派生源为 `observer08r3.c`。DLL 为隔离测试而含有父目录的两个 `og08_test_*` 消费者；整合时必须剔除，不能将测试 DLL 直接部署为 BIOS。

此修正只解决目录代次和私有票据生命期。其他菜单识别、保留原生命周期的入口保护仍需在统一组件中组合验证。没有生成 BIOS 映像或操作硬件。
