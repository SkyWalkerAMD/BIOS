# 页面代次观察器的独立审查

最终结论见 `review.json`，文件绑定见 `component_manifest.json`。审查保留了最初反例和后续修正，未改动任何已冻结的生产者输入。

第一版在服务返回后缺少部分身份检查：两个只读查询、effect 票据创建及 management 票据验证能短暂报告失效状态为成功。第二版修复了这些问题。随后通过原厂 `B8DC` 的实际 CALL 和编译后的嵌套 Loop 包装器发现：内层退出会清除仍属于外层的占用记录。第三版按退出 frame 地址和 depth 退休票据，修复了这个问题。

第三版独立复放 7 个用例全部通过，包括前述反例、普通 foreign 页面更新正例，以及有、无页面更新时的真实嵌套调用。没有页面更新时，外层票据返回后继续有效；发生更新时，旧票据仍然失效且保持占用。两种情形都拒绝原持有者离开前的再次创建。

这些用例执行实际候选 PE、私有包装器和注册的通知函数。服务、对象、调度和原 BrowserLoop 中段仍是明确的测试夹具。management 调用者地址也是边界夹具；本报告不把它称为原 ConfigAccess CALL 的完整执行。嵌套 effect 用例不等于 manage/lease 所有动态分支均已覆盖。

后续整合必须采用第三版修正，并排除 `test_consumer.c`、两个 `og08_test_*` 出口及它们的调用窗口。导航、外部页面和管理组件仍需共同重新链接验证。审查没有写入密码或超频变量，没有执行硬件操作，也不证明完整 BIOS 启动或 FlashBack 可接受性。

`finalize_review.py` 只读取生产者文件并生成本目录报告。运行时需显式传入生产者冻结后的第三版清单 SHA；它不重新构建、不重跑生产者测试。
